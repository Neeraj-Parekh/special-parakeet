02 · SOLUTION

RTO Trust Layer — a merchant risk command center with a bounded AI operator.

Not a model. Not a chatbot. A platform where every decision is cost-optimal, explainable, and audit-sealed.

01

Decide

Every order gets a 3-way verdict — ACCEPT / REVIEW / REJECT — with thresholds derived from the merchant's own cost structure (Bahnsen cost-sensitive BMR), never a static pincode blocklist.

ACCEPT REVIEW · OTP REJECT
02

Explain

Inline TreeSHAP ships every decision with ranked, signed reason codes:

"73% risk because: COD + ₹12,400 + new customer + vague address."

A CFO can read it. A regulator can verify it.

03

Guard

The AI operator works inside a 7-action allowlist. Refusals are enforced by a deterministic classifier BEFORE any LLM call — "block order" can never return anything but refused. Money-moving actions need dual-control HMAC co-signs.
