04 · USP

Four things nobody else ships together.

01
Memory beats pincode

Incumbents flag postal codes. We underwrite the customer: 79-dim per-customer history is the feature family that produced the 32× lift. A good repeat customer in a bad PIN ships normally.

02
Bounded by construction, not by prompt

The operator console's refusals are enforced by a deterministic classifier that runs BEFORE the LLM. Read src/app/api/copilot/route.ts: there is no code path where "block order" returns anything but refused. OC-201B caps are enforced the same way — 422 on breach.

03
Regulator-ready by design

Merkle-sealed audit (RFC 6962 proofs), dual-control HMAC overrides, kill-switch, drift monitors, red-team docs — mapped 1:1 to RBI's June 2026 MRM guidance in docs/RBI_MRM_MAPPING.md.

04
The merchant owns the economics

Rules DSL (compile-checked, no eval) + live cost-curve sliders. Thresholds come from the merchant's own FP/FN costs — not a black box they can't tune.

Incumbent comparison kept honest: incumbents have distribution (millions of merchants); we have the decision infrastructure distribution needs.
