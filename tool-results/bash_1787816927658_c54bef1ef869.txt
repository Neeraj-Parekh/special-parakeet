- Step 3 src/ml/drift.py (NEW, 244 lines): pure-Python + `math` + `collections.deque` (no new deps — numpy only used in `psi()` batch). `class DDM` — survey §3.2 implementation. The well-known DDM degeneracy guard (when the model is perfect, p collapses to 0 → σ_min collapses to 0 → 3σ threshold becomes 0 → every sample fires DRIFT) is fixed by gating the baseline update on `σ > 0` AND gating the WARNING/DRIFT fire on `σ_min > 0` (standard MOA-style fix — documented in the docstring with the degeneracy explanation). Survey §3.2's `p_min` is `p` at the minimum point (NOT `p+σ` — the survey stores p_min and σ_min separately, so `p_min + σ_min` IS the (p+σ) value at the minimum point). Initial bug fix: I first stored `p_min = p+σ`; the test `test_ddm_warning_before_drift` failed (all STABLE on a 100% error burst) because the baseline kept "chasing" the rising error rate. Fixed by storing `p_min = p` per the survey's exact spec. `reset()` called after a confirmed DRIFT (the survey §4 recommendation: re-establish the baseline from the new concept). `class ADWIN` — survey §3.3 + Bifet & Gavalda 2007. `deque(maxlen=10_000)` for bounded memory. Midpoint cut check (simpler than the full all-cut-points ADWIN — survey §3.3 ablation says midpoint is ~99% as effective). On cut, keeps only the second (more recent) half — drops the older concept. Marginal-cut = WARNING (sub-threshold shift), strong-cut = DRIFT (>2·ε_cut). `detect_drift_stream()` batch helper for replay / prequential evaluation (Gama 2014 §5).

Sealing triggers: count-based (default 1000 records) OR time-based (default 3600s since interval opened) — whichever trips first. Padding rule RFC 6962-style: pad leaves to next power of 2 by repeating the LAST leaf's hash (no synthetic zero-leaf that a verifier would need to special-case).
