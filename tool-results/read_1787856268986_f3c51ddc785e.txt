     1→"""KaggleFeatureBuilder — transforms a raw order dict into the 79-dim
     2→feature matrix the Kaggle-trained champion HistGB model expects.
     3→
     4→Wave 3 (Subagent 15-d) — CRITICAL wiring. Closes the gap between:
     5→
     6→  * the **registry** (where the champion ``rto_kaggle_histgb_20260827``
     7→    is registered with priors ``p_orig=0.016979``, ``p_und=0.016979``)
     8→    AND
     9→  * the **inference path** (which until this wave loaded the stub
    10→    ``out/model_api.joblib`` instead of the real Kaggle model at
    11→    ``models/champion/model.pkl``).
    12→
    13→The champion ``model.pkl`` is a *dict* (not a bare estimator) with keys:
    14→
    15→  * ``model``     — the fitted ``HistGradientBoostingClassifier``
    16→  * ``pre``       — a fitted ``sklearn.compose.ColumnTransformer``
    17→    (``OneHotEncoder(handle_unknown='ignore', min_frequency=0.005)`` +
    18→    ``StandardScaler(with_mean=False)`` pipeline) that maps **35 base
    19→    features** → **79 OHE'd columns**
    20→  * ``feat_names`` — the 79 output column names (matches
    21→    ``feature_list.json`` base features + OHE expansion)
    22→  * ``best_thr``  — the best F1 threshold (0.0548)
    23→  * ``pr_auc``    — the Kaggle test PR-AUC (0.1027 = 6.05x baseline)
    24→  * ``config``    — the Kaggle job tag (``"QtyZero_Region_histgb"``)
    25→
    26→Because the champion bundle **already carries the fitted preprocessor**,
    27→we do NOT re-fit a fresh OneHotEncoder at inference (the spec's
    28→``models/champion/ohe_fitter.joblib`` artifact is a thin re-export of the
    29→champion's ``pre`` for spec-compliance + as a fallback when the full
    30→``model.pkl`` isn't loadable — e.g. version-skew across sklearn
    31→releases).
    32→
    33→INFERENCE-TIME APPROXIMATIONS (documented honestly per the task spec):
    34→======================================================================
    35→
    36→1. **Rate features** — during Kaggle training these were *expanding-window*
    37→   means (``df.groupby(key)["rto"].transform(lambda s:
    38→   s.shift(1).expanding().mean())``) — leakage-safe per V3 §"Training
    39→   feature blueprint". At INFERENCE we don't have the training data, so
    40→   we proxy them via ``rate_lookup.json`` computed from
    41→   ``reports/kaggle/feature_preview_1000.csv`` (the 1000-row sample).
    42→   When a key isn't in the lookup, we fall back to the global RTO rate
    43→   (0.016979 — from ``priors.json``). This is a documented
    44→   approximation; the training-time expanding-window features cannot be
    45→   perfectly replicated without the full training set. The proxy's
    46→   expected direction is correct (categories with higher historical RTO
    47→   rates get higher proxy values); the magnitudes are noisier than the
    48→   training-time values (the proxy is a 1000-row sample, not the 96944-
    49→   row training set + not expanding-window).
    50→
    51→2. **OHE vocabulary** — the champion's ``pre`` ColumnTransformer
    52→   ALREADY carries the fitted ``OneHotEncoder`` (with
    53→   ``handle_unknown='ignore'`` + ``min_frequency=0.005``). We use that
    54→   directly. Unseen categories at inference time are silently mapped to
    55→   the ``infrequent_sklearn`` column (or all-zeros for categories never
    56→   seen at all) — exactly the same behaviour the Kaggle training script
    57→   baked in.
    58→
    59→3. **Missing OrderIn fields** — the live ``OrderIn`` Pydantic schema (see
    60→   ``src/api/routes.py``) carries: ``order_id``, ``amount_inr``,
    61→   ``category``, ``customer_id``, ``address_quality``, ``city_tier``,
    62→   ``payment_method``, ``prior_orders``, ``prior_returns``, ``items``,
    63→   ``order_hour``, ``device``, ``merchant_id``. The Kaggle 35-base-feature
    64→   schema needs MORE fields (``state``, ``city``, ``pincode``, ``Qty``,
    65→   ``fulfilment``, ``sales_channel``, ``ship_service_level``,
    66→   ``fulfilled_by``, ``has_promotion``, ``is_b2b``, ``Size``, ``SKU``).
    67→   For each missing field we use a sensible default (e.g.
    68→   ``fulfilment="Merchant"``, ``Qty=order.items``, ``pincode=""``) so the
    69→   smoke test with just the OrderIn fields returns a valid 79-dim matrix.
    70→   The defaults are HONESTLY recorded in ``DEFAULTS`` below + in the
    71→   per-field comments so an operator auditing an inference-time decision
    72→   can see which fields were synthesized vs supplied by the caller.
    73→
    74→References
    75→----------
    76→* Kaggle training script — Amazon Sale Report.csv, 128975 rows, 1.64%
    77→  RTO rate, time-split 80/20, HistGB.
    78→* Bahnsen et al. ICMLA 2013, DOI 10.1109/ICMLA.2013.68 — Eq.(6)
    79→  ``P*(f|x) = P(f|x) · P_orig / P_und`` (the priors calibration this
    80→  builder's output feeds into via routes.py's
    81→  ``calibrate_probabilities`` call site).

   166→
   167→class KaggleFeatureBuilder:
   168→    """Transform a raw order dict into the 79-dim matrix the Kaggle
   169→    champion HistGB model expects.
   170→
   171→    Construction
   172→    ------------
   173→    Preferred path — load from the committed champion bundle::
   174→
   175→        builder = KaggleFeatureBuilder.from_champion_dir("models/champion")
   176→        X = builder.transform(order_dict)  # shape (1, 79)
   177→
   178→    The ``from_champion_dir`` classmethod reads ``model.pkl`` (the dict
   179→    with ``pre`` + ``model`` + ``feat_names``), ``train_stats.json`` (the
   180→    ``amount_bins`` + ``cat_mean`` / ``cat_std`` / ``cat_median`` maps),
   181→    ``priors.json`` (the global RTO rate fallback), and
   182→    ``rate_lookup.json`` (the per-key rate proxies — generated by
   183→    :meth:`build_artifacts` from the 1000-row preview CSV when the
   184→    champion bundle is committed).
   185→
   186→    Transform
   187→    ---------
   188→    :meth:`transform` takes a raw order dict (the ``OrderIn.model_dump()``
   189→    shape + optionally the extra Kaggle fields like ``state``, ``city``,
   190→    ``pincode``, ``Qty``, ``fulfilment``, ``sales_channel``,
   191→    ``ship_service_level``, ``fulfilled_by``, ``has_promotion``,
   192→    ``is_b2b``, ``Size``, ``SKU``, ``created_at``). For each missing
   193→    field it uses the documented :data:`DEFAULTS`. It then:
   194→
   195→      1. Computes the 35-base-feature dict (the
   196→         ``pre.feature_names_in_`` columns — the champion's actual fit
   197→         schema, NOT the static :data:`BASE_FEATURES` list which is
   198→         documentary only).
   199→      2. Builds a single-row pandas DataFrame with those columns.
   200→      3. Calls ``self.pre.transform(df)`` to get the 79-dim OHE'd matrix.
   201→      4. Returns the matrix as a ``numpy.ndarray`` of shape ``(1, 79)``.
   202→
   203→    Honesty
   204→    -------
   205→    The rate features at inference are *proxies* (per-key mean from the
   206→    1000-row preview CSV, NOT the training-time expanding-window means).
   207→    The OHE vocabulary is the *real* champion vocabulary (no fresh fit).
   208→    Missing OrderIn fields are filled with sensible defaults — documented
   209→    in :data:`DEFAULTS` and visible in the source.
   210→    """
   211→
   212→    def __init__(
   213→        self,
   214→        preprocessor: Any,
   215→        feat_names: list[str],
   216→        train_stats: dict[str, Any],
   217→        priors: dict[str, Any],
   218→        rate_lookup: dict[str, dict[str, float]] | None = None,
   219→        champion_dir: str | Path | None = None,
   220→    ):
   221→        """Construct from already-loaded artifacts.
   222→
   223→        Most callers should use :meth:`from_champion_dir` instead — this
   224→        constructor is for tests + the rare case where the artifacts are
   225→        loaded separately (e.g. the OHE fitter joblib fallback path).
   226→        """
   227→        self.pre = preprocessor
   228→        self.feat_names = list(feat_names)
   229→        self.train_stats = dict(train_stats)
   230→        self.priors = dict(priors)
   231→        self.rate_lookup = rate_lookup if rate_lookup is not None else {}
   232→        self.champion_dir = str(champion_dir) if champion_dir else None
   233→
   234→        # Cache the train_stats sub-dicts for fast lookup in transform().
   235→        self._amount_bins: list[float] = list(self.train_stats.get("amount_bins", []))
   236→        self._cat_mean: dict[str, float] = dict(self.train_stats.get("cat_mean", {}))
   237→        self._cat_std: dict[str, float] = dict(self.train_stats.get("cat_std", {}))
   238→        self._cat_median: dict[str, float] = dict(self.train_stats.get("cat_median", {}))
   239→
   240→        # The global RTO rate — the fallback for any rate feature whose
   241→        # key isn't in rate_lookup. From priors.json's p_orig (the
   242→        # original training-set positive rate — 0.016979 for the Kaggle
   243→        # champion).
   244→        self._global_rate: float = float(self.priors.get("p_orig", 0.016979))
   245→
   246→        # The champion's ``pre`` ColumnTransformer's expected input
   247→        # columns (the 35-base-feature schema — the order the OHE was
   248→        # fit on during Kaggle training). Used as the DataFrame's column
   249→        # order in transform().
   250→        self._input_cols: list[str] = list(
   251→            getattr(self.pre, "feature_names_in_", BASE_FEATURES)
   252→        )
   253→
   254→        # Defensive: if the input_cols don't match the expected 35 (e.g.
   255→        # the champion bundle was trained with a slightly different
   256→        # schema), log but don't crash — the transform will still work
   257→        # because we build the row from self._input_cols.
   258→        if len(self._input_cols) != 35:
   259→            warnings.warn(
   260→                f"KaggleFeatureBuilder: champion pre expects "
   261→                f"{len(self._input_cols)} input cols (expected 35). "
   262→                f"Transform will still work but the schema may have drifted.",
   263→                UserWarning,
   264→                stacklevel=2,
   265→            )

   271→    @classmethod
   272→    def from_champion_dir(
   273→        cls, champion_dir: str | Path = "models/champion"
   274→    ) -> "KaggleFeatureBuilder":
   275→        """Load all champion artifacts + construct the builder.
   276→
   277→        Reads:
   278→          * ``model.pkl``              — dict with ``pre``, ``model``,
   279→            ``feat_names``, ``best_thr``, ``pr_auc``, ``config``
   280→          * ``train_stats.json``       — amount_bins + cat_mean/std/median
   281→          * ``priors.json``            — p_orig, p_und (the priors)
   282→          * ``rate_lookup.json``       — per-key rate proxies (optional;
   283→            falls back to global rate for all features when absent)
   284→          * ``schema.json``            — feature_columns (documentary)
   285→
   286→        Returns
   287→        -------
   288→        KaggleFeatureBuilder
   289→            The configured builder. Call :meth:`transform` per order.
   290→        """
   291→        champion_dir = Path(champion_dir)
   292→        # Late import so the module's top-level import is cheap (the
   293→        # sklearn version-skew warning filter is already installed at
   294→        # the top of the module).
   295→        import joblib
   296→
   297→        model_path = champion_dir / "model.pkl"
   298→        if not model_path.exists():
   299→            raise FileNotFoundError(
   300→                f"champion model.pkl not found at {model_path} — "
   301→                f"run scripts/register_champion.py first or pass a "
   302→                f"champion_dir that contains the committed Kaggle artifacts"
   303→            )
   304→        bundle = joblib.load(model_path)
   305→        if not isinstance(bundle, dict) or "pre" not in bundle:
   306→            raise ValueError(
   307→                f"champion model.pkl at {model_path} is not the expected "
   308→                f"dict-with-keys shape (expected keys: model, pre, "
   309→                f"feat_names, ...; got: "
   310→                f"{type(bundle).__name__ if not isinstance(bundle, dict) else list(bundle.keys())})"
   311→            )
   312→        pre = bundle["pre"]
   313→        feat_names = list(bundle.get("feat_names", []))
   314→
   315→        train_stats = cls._load_json(champion_dir / "train_stats.json")
   316→        priors = cls._load_json(champion_dir / "priors.json")
   317→        rate_lookup_path = champion_dir / "rate_lookup.json"
   318→        rate_lookup = (
   319→            cls._load_json(rate_lookup_path)
   320→            if rate_lookup_path.exists()
   321→            else {}
   322→        )
   323→        if not isinstance(rate_lookup, dict):
   324→            rate_lookup = {}
   325→
   326→        return cls(
   327→            preprocessor=pre,
   328→            feat_names=feat_names,
   329→            train_stats=train_stats,
   330→            priors=priors,
   331→            rate_lookup=rate_lookup,
   332→            champion_dir=str(champion_dir),
   333→        )
   334→
   335→    @staticmethod
   336→    def _load_json(path: Path) -> dict:
   337→        if not path.exists():
   338→            return {}
   339→        return json.loads(path.read_text())
   340→
   341→    # ------------------------------------------------------------------
   342→    # Artifact generation (run once when committing the champion bundle)
   343→    # ------------------------------------------------------------------
   344→
   345→    @classmethod
   346→    def build_artifacts(
   347→        cls,
   348→        champion_dir: str | Path = "models/champion",
   349→        preview_csv: str | Path = "reports/kaggle/feature_preview_1000.csv",
   350→    ) -> dict[str, Path]:
   351→        """Generate ``rate_lookup.json`` + ``ohe_fitter.joblib`` from the
   352→        preview CSV + the champion model bundle.
   353→
   354→        Run this ONCE after committing a new champion (or after
   355→        refreshing the preview CSV). The artifacts are checked into the
   356→        repo so the inference path doesn't need the 1000-row sample at
   357→        runtime.
   358→
   359→        * ``rate_lookup.json`` — per-key mean RTO rate proxies computed
   360→          from the preview CSV. Shape::
   361→
   362→              {
   363→                "category": {"KURTA": 0.007, "SET": 0.005, ...},
   364→                "state": {"MAHARASHTRA": 0.006, ...},
   365→                "city": {"BENGALURU": 0.012, ...},
   366→                "pincode_prefix": {"560": 0.011, ...},
   367→                "sku_prefix": {"JNE": 0.005, ...},
   368→                "fulfilment": {"AMAZON": 0.005, "MERCHANT": 0.014, ...},
   369→                "_global": 0.007
   370→              }
   371→
   372→          Keys absent from the lookup fall back to ``_global`` at
   373→          inference time. NOTE: the preview CSV's RTO rate (0.007) is
   374→          noisier than the full training set's 0.016979 — the
   375→          :meth:`from_champion_dir` constructor prefers the
   376→          ``priors.json`` p_orig (0.016979) for the global fallback;
   377→          this ``_global`` key is the proxy-sample global, kept for
   378→          audit/debug.
   379→
   380→        * ``ohe_fitter.joblib`` — a re-export of the champion's ``pre``
   381→          ColumnTransformer. The transform path uses ``pre`` from
   382→          ``model.pkl`` directly (it's the same object); this artifact
   383→          is a spec-compliance artifact + a fallback for environments
   384→          where the full ``model.pkl`` can't be unpickled (sklearn
   385→          version skew).
   386→        """
   387→        champion_dir = Path(champion_dir)
   388→        preview_csv = Path(preview_csv)
   389→        if not preview_csv.exists():
   390→            raise FileNotFoundError(
   391→                f"preview CSV not found at {preview_csv} — needed to "
   392→                f"compute rate_lookup.json (the per-key RTO rate proxies)"
   393→            )
   394→        df = pd.read_csv(preview_csv)
   395→
   396→        # Defensive: the preview CSV's columns are the Kaggle-script
   397→        # intermediate names (e.g. ``Category``, ``ship-state``,
   398→        # ``ship-city``, ``_pincode_prefix``, ``_sku_prefix``,
   399→        # ``Fulfilment``, ``rto``).
   400→        if "rto" not in df.columns:
   401→            raise ValueError(
   402→                f"preview CSV {preview_csv} missing 'rto' column — "
   403→                f"can't compute rate proxies"
   404→            )
   405→        global_rate = float(df["rto"].mean())
   406→
   407→        rate_lookup: dict[str, dict[str, float]] = {"_global": global_rate}
   408→
   409→        # Per-key rate proxies.
   410→        # Map Kaggle preview-CSV column name → rate_lookup key name.
   411→        key_cols = [
   412→            ("Category", "category"),
   413→            ("ship-state", "state"),
   414→            ("ship-city", "city"),
   415→            ("_pincode_prefix", "pincode_prefix"),
   416→            ("_sku_prefix", "sku_prefix"),
   417→            ("Fulfilment", "fulfilment"),
   418→        ]
   419→        for csv_col, key in key_cols:
   420→            if csv_col not in df.columns:
   421→                rate_lookup[key] = {}
   422→                continue
   423→            # Convert the column to string for the lookup keys
   424→            # (e.g. ``_pincode_prefix`` is int 560 → "560").
   425→            grouped = df.groupby(df[csv_col].astype(str))["rto"].mean()
   426→            rate_lookup[key] = {str(k): float(v) for k, v in grouped.items()}
   427→
   428→        # Write rate_lookup.json
   429→        champion_dir.mkdir(parents=True, exist_ok=True)
   430→        rate_lookup_path = champion_dir / "rate_lookup.json"
   431→        rate_lookup_path.write_text(json.dumps(rate_lookup, indent=2))
   432→
   433→        # Re-export the champion's `pre` to ohe_fitter.joblib (spec
   434→        # compliance — the transform path uses `pre` from model.pkl
   435→        # directly; this artifact is a fallback for the rare case where
   436→        # model.pkl can't be unpickled but the user has a standalone
   437→        # pre-fitted preprocessor saved separately).
   438→        model_path = champion_dir / "model.pkl"
   439→        if model_path.exists():
   440→            import joblib
   441→            bundle = joblib.load(model_path)
   442→            if isinstance(bundle, dict) and "pre" in bundle:
   443→                ohe_path = champion_dir / "ohe_fitter.joblib"
   444→                joblib.dump(bundle["pre"], ohe_path)
   445→
   446→        return {
   447→            "rate_lookup": rate_lookup_path,
   448→            "ohe_fitter": champion_dir / "ohe_fitter.joblib"
   449→            if model_path.exists() else None,
   450→        }

   454→    # ------------------------------------------------------------------
   455→
   456→    def transform(self, raw_order: dict) -> np.ndarray:
   457→        """Transform a raw order dict into the 79-dim feature matrix.
   458→
   459→        Parameters
   460→        ----------
   461→        raw_order : dict
   462→            The order. The ``OrderIn.model_dump()`` shape works (with
   463→            defaults for the missing Kaggle-specific fields); a richer
   464→            dict carrying the extra Kaggle fields (``state``, ``city``,
   465→            ``pincode``, ``Qty``, ``fulfilment``, ``sales_channel``,
   466→            ``ship_service_level``, ``fulfilled_by``, ``has_promotion``,
   467→            ``is_b2b``, ``Size``, ``SKU``, ``created_at``) gives more
   468→            accurate features.
   469→
   470→        Returns
   471→        -------
   472→        numpy.ndarray
   473→            Shape ``(1, 79)`` — the OHE'd + scaled matrix the champion
   474→            HistGB ``model.predict_proba`` expects.
   475→        """
   476→        row = self._build_base_features(raw_order)
   477→        # Build a single-row DataFrame in the EXACT column order the
   478→        # champion's `pre` ColumnTransformer was fit on. Missing columns
   479→        # would cause a sklearn AttributeError at transform time.
   480→        df = pd.DataFrame([row], columns=self._input_cols)
   481→        # Coerce categorical columns to string dtype (the OHE expects
   482→        # strings; pandas may infer numeric for columns like pincode_region
   483→        # when the value is "1"). For the numeric columns we coerce to
   484→        # float so the StandardScaler doesn't choke on int.
   485→        for col in self._input_cols:
   486→            if col in self._categorical_input_cols():
   487→                df[col] = df[col].astype(str)
   488→            else:
   489→                df[col] = pd.to_numeric(df[col], errors="coerce").fillna(0.0)
   490→        X = self.pre.transform(df)
   491→        # Defensive: ensure 2D + shape (1, 79). The OHE has
   492→        # sparse_output=False so X is already a dense ndarray; this is
   493→        # a belt-and-braces reshape.
   494→        X = np.asarray(X)
   495→        if X.ndim == 1:
   496→            X = X.reshape(1, -1)
   497→        return X
   498→
   499→    def transform_batch(self, raw_orders: list[dict]) -> np.ndarray:
   500→        """Transform a batch of orders into the (n, 79) matrix.
   501→
   502→        Convenience for batch scoring (e.g. the /v1/policy/cost-curves
   503→        endpoint could use this to score the training set in one shot).
   504→        """
   505→        if not raw_orders:
   506→            return np.zeros((0, len(self.feat_names)))
   507→        rows = [self._build_base_features(o) for o in raw_orders]
   508→        df = pd.DataFrame(rows, columns=self._input_cols)
   509→        for col in self._input_cols:
   510→            if col in self._categorical_input_cols():
   511→                df[col] = df[col].astype(str)
   512→            else:
   513→                df[col] = pd.to_numeric(df[col], errors="coerce").fillna(0.0)
   514→        return np.asarray(self.pre.transform(df))
   515→
   516→    # ------------------------------------------------------------------
   517→    # Internal: build the 35-base-feature dict from a raw order
   518→    # ------------------------------------------------------------------
   519→
   520→    def _categorical_input_cols(self) -> set[str]:
   521→        """Return the set of input cols that are categorical (OHE'd)."""
   522→        # The champion's `pre` ColumnTransformer's first transformer is
   523→        # the categorical OneHotEncoder; its column list (index 2 of the
   524→        # transformer tuple) is what we need.
   525→        try:
   526→            cat_cols = list(self.pre.transformers_[0][2])
   527→        except (AttributeError, IndexError):
   528→            cat_cols = []
   529→        return set(cat_cols)
   530→
   531→    def _build_base_features(self, raw_order: dict) -> dict[str, Any]:
   532→        """Build the 35-base-feature dict from a raw order.
   533→
   534→        Honesty: the rate features (``category_rto_rate``,
   535→        ``state_rto_rate``, etc.) are *proxies* from the 1000-row
   536→        preview CSV (per-key mean), NOT the training-time expanding-window
   537→        means. Keys not in the lookup fall back to the global RTO rate
   538→        (0.016979 — from priors.json's p_orig).
   539→        """
   540→        o = dict(raw_order)  # shallow copy so we don't mutate the caller's dict
   541→
   542→        # --- Pull fields with defaults ---
   543→        amount_inr = float(o.get("amount_inr", 0.0))
   544→        category = str(o.get("category", "KURTA")).upper()
   545→        # Normalize: Kaggle training script appears to have UPPER-cased
   546→        # the Category column (the OHE vocab is all-caps: BLOUSE, KURTA,
   547→        # SET, etc.). The preview CSV has mixed-case ('kurta', 'Set')
   548→        # so the script must have upper-cased before OHE. We do the same.
   549→        state = str(o.get("state", DEFAULTS["state"])).upper()
   550→        city = str(o.get("city", DEFAULTS["city"])).upper()
   551→        pincode = str(o.get("pincode", DEFAULTS["pincode"]))
   552→        # Qty defaults to order.items if not supplied (the closest
   553→        # analog in the OrderIn schema; both are "quantity of items
   554→        # in the order").
   555→        qty = o.get("Qty", o.get("qty", DEFAULTS["Qty"]))
   556→        if qty is None:
   557→            qty = o.get("items", 1)
   558→        qty = int(qty) if qty is not None else 1
   559→        fulfilment = str(o.get("fulfilment", DEFAULTS["fulfilment"])).upper()
   560→        sales_channel = str(o.get("sales_channel", DEFAULTS["sales_channel"])).upper()
   561→        ship_service_level = str(
   562→            o.get("ship_service_level", DEFAULTS["ship_service_level"])
   563→        ).upper()
   564→        fulfilled_by = str(o.get("fulfilled_by", DEFAULTS["fulfilled_by"])).upper()
   565→        has_promotion = int(bool(o.get("has_promotion", DEFAULTS["has_promotion"])))
   566→        is_b2b = int(bool(o.get("is_b2b", DEFAULTS["is_b2b"])))
   567→        size = str(o.get("Size", o.get("size", DEFAULTS["Size"])))
   568→        sku = str(o.get("SKU", o.get("sku", DEFAULTS["SKU"])))
   569→        created_at = o.get("created_at", DEFAULTS["created_at"])
   570→
   571→        # --- Derived features ---
   572→        amount_log = float(np.log1p(max(amount_inr, 0.0)))
   573→        # amount_bucket: bin via the 5-bin edges from train_stats.json
   574→        # amount_bins ([-inf, 406, 530, 685, 836, +inf]). Map to q1..q5.
   575→        amount_bucket = self._bin_amount(amount_inr)
   576→        is_high_value = int(amount_inr > 5000)
   577→        is_very_high_value = int(amount_inr > 10000)
   578→        # amount_zscore_by_category: (amount - cat_mean) / cat_std.
   579→        # Fall back to 0.0 when the category isn't in the train_stats
   580→        # (unseen category → no zscore possible).
   581→        cat_mean = self._cat_mean.get(category)
   582→        cat_std = self._cat_std.get(category)
   583→        if cat_mean is not None and cat_std is not None and cat_std > 0:
   584→            amount_zscore = (amount_inr - cat_mean) / cat_std
   585→        else:
   586→            amount_zscore = 0.0
   587→        cat_median = self._cat_median.get(category)
   588→        amount_ratio = (
   589→            float(amount_inr / cat_median) if cat_median and cat_median > 0 else 1.0
   590→        )
   591→        amount_per_qty = float(amount_inr / max(qty, 1))
   592→        # pincode_prefix: first 3 chars of the pincode string (the Kaggle
   593→        # script's _pincode_prefix column). Used for the rate lookup.
   594→        pincode_prefix = pincode[:3] if pincode else ""
   595→        pincode_length = len(pincode) if pincode else 0
   596→        # pincode_region: first digit of the pincode (1-8 for India's
   597→        # postal regions; 0/9 are non-standard). The Kaggle script's
   598→        # pincode_region column.
   599→        pincode_region = pincode[0] if pincode and pincode[0].isdigit() else "0"
   600→        # sku_prefix: first 14 chars per the Kaggle script (spec).
   601→        sku_prefix = sku[:14] if sku else ""
   602→        # cat_has_promo: the Kaggle interaction feature (string like
   603→        # "KURTA_1" — category + "_" + has_promotion). The OHE was fit
   604→        # on this string column.
   605→        cat_has_promo = f"{category}_{has_promotion}"
   606→        # amount_x_promo: the interaction amount * has_promotion.
   607→        amount_x_promo = float(amount_inr * has_promotion)
   608→        is_qty_zero = int(qty == 0)
   609→
   610→        # Datetime features (from created_at if available, else 0).
   611→        hour_of_day = 0
   612→        day_of_week = 0
   613→        month = 0
   614→        is_weekend = 0
   615→        is_month_start = 0
   616→        is_month_end = 0
   617→        if created_at:
   618→            try:
   619→                ts = pd.to_datetime(created_at, errors="coerce")
   620→                if ts is not None and not pd.isna(ts):
   621→                    hour_of_day = int(ts.hour)
   622→                    day_of_week = int(ts.dayofweek)
   623→                    month = int(ts.month)
   624→                    is_weekend = int(day_of_week >= 5)
   625→                    is_month_start = int(ts.is_month_start)
   626→                    is_month_end = int(ts.is_month_end)
   627→            except Exception:
   628→                pass  # leave defaults
   629→
   630→        # courier_status_clean: the Kaggle script's "clean" courier status
   631→        # column. At INFERENCE we don't have a courier status (it's a
   632→        # post-shipment outcome — leakage). The Kaggle training script
   633→        # left it as the raw string or "UNK" for missing; the champion's
   634→        # OHE was fit on the training values. We pass "UNK" — the OHE
   635→        # maps it to infrequent_sklearn (or all-zeros) at inference.
   636→        courier_status_clean = "UNK"
   637→
   638→        # --- Rate features (INFERENCE-TIME PROXIES) ---
   639→        # Per-key lookup in self.rate_lookup (computed from the 1000-row
   640→        # preview CSV). Fall back to the global rate (0.016979) when the
   641→        # key isn't in the lookup. Documented approximation — see the
   642→        # module docstring for the full honesty note.
   643→        category_rto_rate = self._lookup_rate("category", category)
   644→        state_rto_rate = self._lookup_rate("state", state)
   645→        city_rto_rate = self._lookup_rate("city", city)
   646→        pincode_prefix_rto_rate = self._lookup_rate("pincode_prefix", pincode_prefix)
   647→        sku_prefix_rto_rate = self._lookup_rate("sku_prefix", sku_prefix)
   648→        fulfilment_rto_rate = self._lookup_rate("fulfilment", fulfilment)
   649→        # Smoothed variants: at inference we don't have the expanding-window
   650→        # smoothing; use the unsmoothed proxy. The champion's `pre`
   651→        # includes city_rto_rate_smooth + pincode_prefix_rto_rate_smooth
   652→        # as separate input columns — we feed them the same proxy value.
   653→        city_rto_rate_smooth = city_rto_rate
   654→        pincode_prefix_rto_rate_smooth = pincode_prefix_rto_rate
   655→        # category_order_count: the training-time cumcount per category
   656→        # (a leaky feature if not shift(1)'d). At inference we don't
   657→        # know the order's position in its category's sequence; use 1
   658→        # (the first sighting in the inference batch — the safest default
   659→        # for a single-order prediction).
   660→        category_order_count = 1
   661→
   662→        # --- Build the row dict in the champion's pre.feature_names_in_
   663→        # order (NOT the static BASE_FEATURES list — the champion's
   664→        # actual fit schema may differ slightly from the schema.json
   665→        # feature_columns list, e.g. the QtyZero_Region_histgb config
   666→        # added cat_has_promo + pincode_region + amount_x_promo +
   667→        # is_qty_zero + city_rto_rate_smooth +
   668→        # pincode_prefix_rto_rate_smooth, replacing some schema cols). ---
   669→        all_features = {
   670→            "category": category,
   671→            "state": state,
   672→            "city": city,
   673→            "pincode_prefix": pincode_prefix,
   674→            "sku_prefix": sku_prefix,
   675→            "fulfilment": fulfilment,
   676→            "sales_channel": sales_channel,
   677→            "ship_service_level": ship_service_level,
   678→            "fulfilled_by": fulfilled_by,
   679→            "amount_bucket": amount_bucket,
   680→            "courier_status_clean": courier_status_clean,
   681→            "hour_of_day": hour_of_day,
   682→            "day_of_week": day_of_week,
   683→            "month": month,
   684→            "amount_inr": amount_inr,
   685→            "amount_log": amount_log,
   686→            "is_high_value": is_high_value,
   687→            "is_very_high_value": is_very_high_value,
   688→            "amount_zscore_by_category": amount_zscore,
   689→            "amount_ratio_to_cat_median": amount_ratio,
   690→            "amount_per_qty": amount_per_qty,
   691→            "Qty": qty,
   692→            "pincode_length": pincode_length,
   693→            "is_weekend": is_weekend,
   694→            "is_month_start": is_month_start,
   695→            "is_month_end": is_month_end,
   696→            "is_b2b": is_b2b,
   697→            "has_promotion": has_promotion,
   698→            "category_rto_rate": category_rto_rate,
   699→            "state_rto_rate": state_rto_rate,
   700→            "city_rto_rate": city_rto_rate,
   701→            "pincode_prefix_rto_rate": pincode_prefix_rto_rate,
   702→            "sku_prefix_rto_rate": sku_prefix_rto_rate,
   703→            "fulfilment_rto_rate": fulfilment_rto_rate,
   704→            "category_order_count": category_order_count,
   705→            # The QtyZero_Region_histgb config's extra derived features
   706→            # (replacing some schema columns; the champion's `pre`
   707→            # was fit on these names).
   708→            "cat_has_promo": cat_has_promo,
   709→            "pincode_region": pincode_region,
   710→            "Size": size,
   711→            "city_rto_rate_smooth": city_rto_rate_smooth,
   712→            "pincode_prefix_rto_rate_smooth": pincode_prefix_rto_rate_smooth,
   713→            "amount_x_promo": amount_x_promo,
   714→            "is_qty_zero": is_qty_zero,
   715→        }
   716→        # The champion's `pre` ColumnTransformer's `feature_names_in_`
   717→        # lists the EXACT 35 columns it expects (in the fit order).
   718→        # We subset our all_features dict to those columns. If any
   719→        # expected column is missing from all_features, default to 0
   720→        # (numeric) or "UNK" (string) — defensive against schema drift.
   721→        row: dict[str, Any] = {}
   722→        for col in self._input_cols:
   723→            if col in all_features:
   724→                row[col] = all_features[col]
   725→            else:
   726→                # Schema drift: the champion expects a column we don't
   727→                # synthesize. Default to 0 (numeric) — the OHE will
   728→                # handle string columns via infrequent_sklearn.
   729→                row[col] = 0
   730→        return row

   732→    def _bin_amount(self, amount: float) -> str:
   733→        """Bin amount into q1..q5 using the train_stats amount_bins edges."""
   734→        if not self._amount_bins or len(self._amount_bins) < 2:
   735→            return "q1"  # fallback: lowest bin
   736→        # amount_bins = [-inf, 406, 530, 685, 836, +inf] → 5 bins q1..q5
   737→        for i in range(len(self._amount_bins) - 1):
   738→            lo = self._amount_bins[i]
   739→            hi = self._amount_bins[i + 1]
   740→            try:
   741→                if (lo == -float("inf") or amount >= lo) and (
   742→                    hi == float("inf") or amount < hi
   743→                ):
   744→                    return f"q{i + 1}"
   745→            except (TypeError, ValueError):
   746→                continue
   747→        return "q1"
   748→
   749→    def _lookup_rate(self, key: str, value: str) -> float:
   750→        """Per-key RTO rate proxy from rate_lookup.json.
   751→
   752→        Falls back to the global RTO rate (0.016979 — from priors.json's
   753→        p_orig) when the key isn't in the lookup. This is the documented
   754→        inference-time approximation: the training-time expanding-window
   755→        means cannot be perfectly replicated without the full training
   756→        set.
   757→        """
   758→        if not value:
   759→            return self._global_rate
   760→        sub = self.rate_lookup.get(key, {})
   761→        if not isinstance(sub, dict):
   762→            return self._global_rate
   763→        # Try the value as-is, then upper-cased (the preview CSV has
   764→        # mixed-case values like 'kurta'; the rate_lookup keys preserve
   765→        # the CSV's case; we lookup with the upper-cased inference value
   766→        # so we match the Kaggle training-time upper-casing convention).
   767→        if value in sub:
   768→            return float(sub[value])
   769→        if value.upper() in sub:
   770→            return float(sub[value.upper()])
   771→        if value.lower() in sub:
   772→            return float(sub[value.lower()])
   773→        return self._global_rate
   774→
   775→    # ------------------------------------------------------------------
   776→    # Convenience: predict_proba (used by tests + the routes.py
   777→    # /risk/score handler as an alternative to the two-step transform +
   778→    # model.predict_proba).
   779→    # ------------------------------------------------------------------
   780→
   781→    def predict_proba(self, raw_order: dict, model: Any) -> float:
   782→        """Transform + predict the RTO probability in one call.
   783→
   784→        Parameters
   785→        ----------
   786→        raw_order : dict
   787→            Same shape as :meth:`transform`.
   788→        model : Any
   789→            The champion's ``model`` (the HistGB estimator extracted
   790→            from the champion ``model.pkl`` dict).
   791→
   792→        Returns
   793→        -------
   794→        float
   795→            The model's predicted P(RTO | x) — a scalar in [0, 1].
   796→        """
   797→        X = self.transform(raw_order)
   798→        proba = model.predict_proba(X)
   799→        return float(proba[0, 1])
